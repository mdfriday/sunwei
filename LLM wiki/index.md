## Concepts

- [[bookkeeping|Bookkeeping]] - 维护知识库的繁琐部分，包括更新交叉引用、保持摘要当前、记录新数据与旧声明的矛盾。 (1 source)
- [[incremental-building|Incremental Building]] - 知识一旦编译就保持当前状态，不每次查询重新推导，随每个来源和问题不断丰富。 (1 source)
- [[indexing|Indexing]] - 使用 index.md 作为内容导向的目录，列出所有页面及其摘要和元数据。 (1 source)
- [[ingest|Ingest]] - 将新源放入原始集合并让 LLM 处理，包括写摘要、更新索引和相关实体页面。 (1 source)
- [[lint|Lint]] - 定期让 LLM 健康检查 Wiki，查找矛盾、过时声明、孤立页面或缺失交叉引用。 (1 source)
- [[logging|Logging]] - 使用 log.md 作为按时间顺序追加的记录，记录摄入、查询和 lint 通过情况。 (1 source)
- [[persistent-wiki|Persistent Wiki]] - LLM 增量构建和维持的持久化 Wiki，是原始源和你之间的结构化互连 Markdown 文件集合。 (1 source)
- [[query|Query]] - 对 Wiki 提问，LLM 搜索相关页面并综合带引用的答案，回答可归档为 Wiki 新页面。 (1 source)
- [[rag|RAG]] - 检索增强生成模式，上传文件后在查询时检索相关片段并生成答案，每次重新发现知识。 (1 source)
- [[raw-sources|Raw Sources]] - 原始源文档的集合（文章、论文等），不可修改，LLM 从中读取但从不修改。 (1 source)
- [[the-schema|The Schema]] - 配置文档（如 CLAUDE.md 或 AGENTS.md），告诉 LLM Wiki 的结构、约定和工作流程。 (1 source)
