## 一句话版本

> 父子两人，从武汉开车出发，穿越湘西苗族山地，深入贵州秘境。
> 每到一个地方，看一片风景，学一件事，做进游戏里。
> 30天后，带回一个「湘西奇境」的 Web 游戏，和一段只属于这趟旅行的记忆。

## 路线概览

```
武汉 → 长沙 → 张家界 → 矮寨 → 凤凰
     → 梵净山 → 贵阳 → 平塘(FAST天眼) → 兴义(万峰林)
     → 贵阳 → 怀化 → 武汉
```

**总里程：约 3800-4200 公里**
**出行方式：丰田 Yaris，全程高速/国道**
**出行人员：父 + 子（12岁）**
**最高海拔：约 2500m（梵净山附近），全程无高原反应风险**

## 暑假人流说明

> 7-8月是湘西和贵州的旅游旺季，人流管理是这趟旅行的核心策略之一。

**核心原则：**
- 热门景点安排在**工作日**（周二至周四最少人）
- **早7点前进景区**，中午11-14点人最多时回酒店休息+做游戏
- 所有需要购票的景区**提前网上预约**
- 下午4点后人少，光线好，再出去拍照

**各地人流预估：**

| 景点 | 暑假人流 | 应对策略 |
|------|---------|---------|
| 张家界武陵源 | 🔴 极多 | 提前2周网上购票，早7点入园 |
| 天门山 | 🟡 较多 | 提前预约缆车，避开周末 |
| 凤凰古城 | 🟡 较多 | 早晨和夜晚最美，避开午间 |
| 矮寨大桥 | 🟢 适中 | 随时可去 |
| 梵净山 | 🟡 较多 | 提前预约，早出发 |
| 西江千户苗寨 | 🟡 较多 | 景区够大，分散游览 |
| 荔波小七孔 | 🟡 较多 | 提前购票，工作日去 |
| 黄果树 | 🟡 较多 | 周末避开，工作日人少一半 |

## 三条核心原则

1. **不赶路** — 每天只做一件主要的事
2. **不强撑** — 孩子不舒服，计划让步
3. **人多就换时间** — 人流高峰是午间，不是全天
