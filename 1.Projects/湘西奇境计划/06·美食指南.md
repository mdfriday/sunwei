# 06 · 美食指南

> 湘西和贵州是中国饮食最有个性的两个地方：一个重辣重香，一个酸辣鲜活。
> 原则：找街边小店，找本地人吃饭的地方，不去景区餐厅。

---

## 长沙（Day 1-2）

**长沙是美食城市，但要找对地方。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **臭豆腐** | 火宫殿旁边的街边摊（不是里面的餐厅） | 外焦里嫩，蘸辣椒，长沙独有 |
| **糖油粑粑** | 早餐街边 | 糯米团炸糖，软糯香甜，孩子喜欢 |
| **口味虾** | 夜宵摊，晚上9点后 | 麻辣，重口，长沙夏夜标配 |
| **剁椒鱼头** | 湘菜馆（不是连锁） | 蒸的，辣椒铺满整个鱼头 |
| **浏阳蒸菜** | 浏阳蒸菜馆 | 食材蒸熟，清淡鲜甜，孩子适合 |

> 💡 长沙早餐：糖油粑粑+豆浆，5块钱，比任何酒店自助早餐都有意思。

## 张家界（Day 3-8）

**土家族是张家界的主体民族，食物和汉族差别明显。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **土家扣肉** | 武陵源周边土家餐馆 | 五花肉蒸到酥烂入味，土家婚宴主角 |
| **合渣** | 街边小馆子 | 豆渣+蔬菜混煮，土家族最家常的食物 |
| **腊肉炒蒜苔** | 当地餐馆 | 自家熏制腊肉，香味很重 |
| **野山椒炒肉** | 任意土家馆子 | 当地产野山椒，比普通辣椒更鲜 |
| **葛根粉** | 景区周边小店 | 当地特产，冲水喝，清凉解渴 |

> 💡 找饭店原则：看到门口挂腊肉的，进去通常都不会错。

## 矮寨 · 德夯（Day 9）

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **苗家酸汤鱼** | 德夯苗寨内餐馆 | 发酵米汤做汤底，酸鲜，完全不同的味型 |
| **糯米饭（五色）** | 苗寨早餐 | 植物染色，红绿黑紫白，节日食物 |
| **苗家米酒** | 当地自酿，问老板要尝尝 | 低度，甜，孩子可以尝一小口 |

## 凤凰古城（Day 10-12）

**凤凰的食物是湘西饮食的集大成。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **血粑鸭** | 古城内街边餐馆（找没有英文菜单的） | 听名字吓人，鸭子炒鸭血糕，香浓，凤凰最有名的菜 |
| **社饭** | 早餐摊（清明前后最正宗，夏天也有） | 野菜+腊肉+糯米，香 |
| **姜糖** | 沱江边糖摊，现场熬制 | 孩子必买，辣中带甜 |
| **苗家酸鱼** | 当地餐馆 | 腌制发酵的鱼，湘西独有，强烈推荐尝一次 |
| **米豆腐** | 早餐，街边 | 米浆凝固的豆腐，配辣椒汁 |

> 💡 血粑鸭的找法：推开没有游客、坐满当地老人的门，进去点这道菜。

## 梵净山周边（Day 13-14）

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **梵净山豆腐干** | 山脚小商店 | 当地特产，烟熏味，结实有嚼劲 |
| **贵州辣子鸡** | 铜仁市区馆子 | 不同于重庆辣子鸡，贵州的更鲜 |
| **折耳根炒腊肉** | 任意贵州餐馆 | 折耳根（鱼腥草）贵州人天天吃，有点奇特味道 |

> 💡 折耳根：外地人第一次吃觉得奇怪，贵州人当菜当零食，入乡随俗尝一次。

## 凯里·苗寨（Day 15-17）

**贵州酸是另一种哲学：不是醋的酸，是发酵的酸。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **红酸汤火锅** | 凯里街边火锅店 | 西红柿发酵的酸汤，鲜红色，鲜得很 |
| **苗家腌鱼** | 苗寨内餐馆 | 腌制1年以上，独特发酵味，勇者食物 |
| **牛瘪火锅** | 不强制推荐，但当地最有名 | 这个需要做好心理准备再点 |
| **糯米甜酒** | 苗寨早餐，现酿现卖 | 浓甜，孩子喜欢 |
| **苗族糯米饭** | 任意苗家餐馆 | 放在竹筒里蒸，有竹香 |

> 💡 红酸汤火锅：凯里的国民食物，每天都可以吃，越吃越上瘾。

## 黄果树 · 贵阳（Day 20-23）

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **贵阳丝娃娃** | 贵阳街头小吃摊 | 薄皮包20多种蔬菜，浇酸辣汁，贵阳人最爱的街头食物 |
| **贵阳肠旺面** | 早餐，街边面馆 | 猪血旺+肥肠+面条，重口但鲜美 |
| **贵阳烤豆腐** | 街边摊，每个路口都有 | 烤到外焦内嫩，蘸辣椒面 |
| **青岩猪脚** | 青岩古镇内 | 卤猪脚，软烂，古镇必吃 |
| **酸汤鱼（贵阳版）** | 正规贵州菜馆 | 比凯里更精致，鱼更新鲜 |

> 💡 贵阳丝娃娃：让孩子自己包，每个人包的形状不一样，像游戏里的DIY关卡。

## 全程通用原则

### 怎么找好吃的

```
1. 看人——门口有本地人排队的，进去
2. 看时间——本地吃饭时间（早7-8点，午11:30-12:30）去
3. 看菜单——只有中文的，更可能是本地店
4. 看装修——越普通越好
5. 问客栈老板——「你自己去哪吃饭？」
```

### 孩子饮食注意

| 情况 | 建议 |
|------|------|
| 辣度 | 湘西贵州菜普遍辣，点菜时说「少辣/不辣」 |
| 酸味 | 贵州酸汤初次尝试，少量即可 |
| 发酵食品 | 腌鱼、苗家腌肉量少尝，肠胃适应 |
| 天气热 | 多喝水，少吃冰（肠胃保护） |

## 食物 × 游戏知识卡

| 食物 | 游戏知识卡问题 |
|------|--------------|
| 土家扣肉 | 土家族和汉族的关系是什么？ |
| 苗家酸汤鱼 | 苗族的酸汤是怎么发酵的？ |
| 凤凰姜糖 | 姜为什么能驱寒？古代有什么用途？ |
| 糯米五色饭 | 五种颜色的植物分别是什么？ |
| 红酸汤 | 西红柿发酵和直接吃有什么区别？ |
| 折耳根 | 鱼腥草为什么叫鱼腥草？有什么药用价值？ |

> 每一道食物，都可以成为游戏里「驿站补给菜单」的一道选项。
> 玩家选择吃什么，决定接下来的冒险能力加成。
