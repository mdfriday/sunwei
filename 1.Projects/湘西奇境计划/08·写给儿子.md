# 08 · 写给儿子

> 爸爸写给你的，出发前先读这一页。

---

## 你知道《阿凡达》里的悬浮山吗

那些从云雾里钻出来的山，蓝色的天空，悬在空中的石柱——

那不是电脑做的。

导演詹姆斯·卡梅隆去中国看了一片山，然后说：**「就是这里。」**

那片山叫**张家界**。

**今年暑假，我们要开车去那里。**

---

## 不只是张家界

从武汉出发，我们会开车走过整个湘西和贵州：

```
张家界   →  石柱凌空，像浮空岛地形
矮寨大桥 →  355米深的峡谷，桥悬在空中
凤凰古城 →  苗族古城，吊脚楼建在江边
梵净山   →  UNESCO世界遗产，云雾里的神山
苗族寨子 →  世界最大苗族村，1300户人家住在山坡上
荔波     →  碧绿色的河流穿过原始森林（真的是那种颜色）
黄果树   →  中国最大瀑布，有个「水帘洞」
```

30天，7个不同的世界。

**每一个，我们都要做进游戏里。**

---

## 我们做的游戏叫「湘西奇境」

游戏故事：一个少年听说湘西有神秘的奇境，独自踏上旅程。
他的目标不是「打通关」，而是**「见过」**。
每见过一样东西，就在他的「奇境图鉴」里多一页记录。

| 游戏章节 | 真实地点 | 你会遇到什么 |
|---------|---------|------------|
| 第一章·浮空山脉 | 张家界 | 石柱王国、金鞭猴群、天门洞守卫 |
| 第二章·深渊古城 | 矮寨+凤凰 | 深渊大桥、江边苗族、边城翠翠 |
| 第三章·神山部落 | 梵净山+苗寨 | 云雾金顶、苗族银匠、万家灯火 |
| 第四章·碧水秘境 | 荔波+黄果树 | 精灵森林、水帘洞、瀑布水仙 |

## 还有「湘西武者列传」

| 地点 | 你的必杀技 |
|------|----------|
| 张家界袁家界悬崖边 | **浮空裂山拳** |

| 梵净山红云金顶 | **神山降魔拳** |

爸爸写代码。你负责：

## 今天就可以开始的5件事

**① 把你的游戏拿出来，和爸爸讨论**

你已经做过一个游戏了。

我们一起看：代码结构怎么样？如果要加一个「张家界浮空山脉」关卡，你打算怎么做？

**② 用AI生成游戏主角**

打开ChatGPT，输入：
```
画一个12岁的中国少年，
穿着轻便的探险服装，背着一个装满图鉴的背包，
像素风格，16x16像素，透明背景，游戏角色
```

不满意就继续说「更酷一点」「加一把短剑」。

这个角色就是游戏主角。

**③ 用Suno做游戏标题音乐**

打开suno.com，输入：
```
mysterious western hunan adventure game title screen,
Chinese ethnic minority music, flute and drums,
8-bit retro pixel game style, exciting and curious
```

30秒后你会听到一首真实的游戏音乐。

**④ 开始你的「奇境问题本」**

找一个本子，写下你现在对这趟旅行已经有的问题。

比如：
- 「张家界的石柱为什么不会倒？」
- 「苗族人为什么这么喜欢银饰？」
- 「水帘洞是真的吗？里面能住人吗？」

30个问题 = 游戏里30张知识卡。

**⑤ 在Minecraft里建一个「浮空岛基地」**

不查资料，用你对「张家界」的想象建一个浮空岛。

去了张家界真正看到之后，再回来对比——
**你猜对了什么？你没想到的是什么？**
