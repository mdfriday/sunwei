## 出发倒计时

### 出发前两周
```
[ ] 武陵源景区票网上购买（最热门，最早）
[ ] 天门山缆车预约
[ ] 梵净山门票+缆车预约
[ ] 荔波小七孔购票
[ ] 确认沿途酒店（凤凰沱江边客栈、西江苗寨内民宿提前订）
[ ] 通知家人行程
```

### 出发前一天
```
[ ] 充电宝充满
[ ] 手机下载离线地图（奥维互动地图）
[ ] 雨衣确认（父子各一件，不是雨伞）
[ ] 防蚊液备足
[ ] 帐篷在家试搭
```

### 出发当天
```
[ ] 油箱加满
[ ] 告知家人出发时间和第一晚落脚点
[ ] 和儿子说：「我们不是去旅游的，我们是去做一件事的。」
```
