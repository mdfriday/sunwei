# 03 · 游戏设计文档

> 游戏名称：**丝路少年**
> 类型：地图探索 + 知识解锁 + 轻量经营
> 平台：Web 浏览器（手机/电脑均可玩）
> 开发者：爸爸 + 儿子 + AI

---

## 核心理念

> 游戏的每一个角色、每一个场景、每一张知识卡，都来自真实的旅程。
> 30天结束时，游戏本身就是旅行纪念册。

---

## 游戏简介

玩家扮演一名从长安出发的少年商人，带领一支小小的商队，沿丝绸之路一路向西。

路途中：
- 探索不同地形（黄土高原 / 高原湖泊 / 戈壁 / 沙漠 / 彩色山脉）
- 收集**知识卡**（每解锁一个就是父子俩在旅途中真实学到的一件事）
- 遇见**NPC**（骆驼商队、藏族牧民、敦煌僧侣、戈壁探险者）
- 建立**驿站**，积累资源，推动商队前进

游戏没有失败条件。
只有「走得更远」和「知道得更多」。

## 游戏章节

### 序章｜少年启程

**对应地点：** 武汉 → 洛阳 → 西安

**解锁内容：**
- 主角登场（少年 + 父亲形象，由孩子手绘草图）
- 商队起点：长安城
- 第一张知识卡：**"丝绸之路从哪里开始？"**

**关卡设计：**
- 在长安城里收集3样出发物资（丝绸 / 茶叶 / 铜钱）
- 对话NPC：老商人，获得第一张地图

---

### 第一章｜黄土与帝国

**对应地点：** 西安 / 天水 / 兰州

**主题：** 古代帝国、丝路起点、黄河文明

**解锁内容：**
- 地图区域：黄土高原
- 新NPC：黄河渡夫、兵马俑卫兵（游戏化版本）
- 新场景：黄河渡口、石窟群

**知识卡（旅途中收集）：**
- 黄河为什么是黄色的？
- 麦积山石窟为什么凿在悬崖上？
- 丝绸之路的商队一天能走多远？

**游戏机制：**
- 解锁黄河渡口后，商队可以横渡黄河，进入高原区域
- 获得第一个交易系统：用丝绸换高原特产

---

### 第二章｜高原与盐湖

**对应地点：** 西宁 / 青海湖 / 茶卡盐湖 / 大柴旦

**主题：** 高原生态、盐湖经济、镜面世界

**解锁内容：**
- 地图区域：青藏高原东缘
- 新NPC：藏族牧民（骑牦牛）、候鸟（斑头雁）
- 新场景：青海湖星空、茶卡盐湖镜面
- 新资源：盐（游戏内最重要的贸易物资）

**知识卡：**
- 青海湖为什么是咸水湖？
- 盐是怎么在湖里形成的？
- 候鸟斑头雁为什么能飞越喜马拉雅？

**游戏机制：**
- 盐矿采集系统：在茶卡盐湖采盐，用盐换取戈壁通行许可
- 星空小游戏：夜晚在青海湖，识别3个星座，解锁「导航知识卡」

**特别设计：** 青海湖页面背景使用父子在黑马河拍摄的真实星空照片。

---

### 第三章｜戈壁与丝路文明

**对应地点：** 格尔木 / 敦煌 / 莫高窟 / 鸣沙山

**主题：** 生存挑战、文明交流、壁画传承

**解锁内容：**
- 地图区域：戈壁 / 敦煌绿洲
- 新NPC：骆驼商队、敦煌僧侣、飞天仙女（壁画中走出来）
- 新场景：鸣沙山沙丘、莫高窟洞窟、月牙泉

**知识卡：**
- 沙漠里的月牙泉为什么没被沙埋？
- 莫高窟的壁画为什么能保存1000年？
- 骆驼为什么适合在沙漠里行走？

**游戏机制：**
- 壁画修复小游戏：还原一张莫高窟壁画图案（使用旅途中拍摄的真实壁画素材）
- 商队绿洲系统：在月牙泉补给后，可解锁西域地图

**特别设计：** 飞天角色由儿子在龙门石窟参观后手绘，AI辅助生成游戏版本。

---

### 第四章｜边塞与彩山

**对应地点：** 嘉峪关 / 张掖丹霞

**主题：** 边境文化、地质奇观、时间尺度

**解锁内容：**
- 地图区域：河西走廊
- 新NPC：长城守卫、丹霞地质学家（NPC）
- 新场景：嘉峪关关城、七彩丹霞

**知识卡：**
- 长城为什么建在嘉峪关这里？
- 山为什么会有颜色？
- 丹霞地貌需要多少年形成？

**游戏机制：**
- 嘉峪关通关挑战：回答3道关于丝绸之路的问题，才能让商队通关
- 地质时间轴：在丹霞场景里，可以拨动「时间轴」看山的颜色如何随地质年代变化

### 终章｜少年归来

**对应地点：** 张掖 → 兰州 → 西安 → 武汉

**主题：** 归途、总结、成长

**解锁内容：**
- 商队成功返回长安
- 解锁「旅行纪念册」：显示收集的所有知识卡 + 真实旅途照片
- 最终成就：**「丝路少年」称号**

**终章设计：**
- 游戏结尾画面：少年和父亲并排站在长安城门口，背后是走过的所有地图
- 配文：「30天，5个章节，一条丝绸之路，一对父子。」

## 特别功能：丝路武者·格斗动画

> 这是整个游戏里最有记忆点的部分。

### 核心玩法

每到一个标志性地点，父子两人在实景中**摆一个格斗动作**拍照。

然后用 AI 把这张照片变成**拳皇97风格的像素格斗动画**。

每个地点对应一个专属「必杀技」，技能名字来自那个地方。

游戏里有一个专属画廊「**丝路武者列传**」，收录父子在每个章节解锁的全部动画。

---

### 每章拍摄计划

| 章节 | 地点 | 拍摄场景 | 必杀技名 |
|------|------|---------|---------|
| 序章 | 西安古城墙上 | 儿子单脚站城垛，背后是城楼 | **「长安出击」** |
| 第一章 | 兰州黄河岸边 | 爸爸跳起，背景是黄河铁桥 | **「黄河翻浪拳」** |
| 第二章 | 青海湖黑马河 | 父子背对背，背景是星空湖面 | **「星空冰裂踢」** |
| 第二章 | 茶卡盐湖 | 儿子在盐面上跳起，反光倒影 | **「镜面幻影步」** |
| 第三章 | 鸣沙山沙丘顶 | 爸爸张开双臂，背后是沙丘曲线 | **「沙暴旋风腿」** |
| 第三章 | 敦煌月牙泉边 | 父子一前一后飞踢姿势 | **「飞天降临拳」** |
| 第四章 | 嘉峪关城楼 | 儿子手指远方，背后是长城 | **「边塞铁壁掌」** |
| 第四章 | 张掖丹霞山脚 | 两人并排，背景是彩色山体 | **「彩虹崩山击」** |

---

### 制作流程（每个地点约20分钟）

```
Step 1  现场拍照
        选好背景构图，父子摆格斗动作
        拍3-5张，选最好的一张

Step 2  AI 生成像素精灵（Midjourney / DALL·E）
        提示词模板：
        「King of Fighters 97 style pixel art fighter sprite,
         based on this photo, 16-bit retro fighting game,
         full body, transparent background,
         action pose, Chinese boy warrior costume」

Step 3  AI 生成动画帧（Kling AI 可灵 或 Runway）
        把像素图生成4-8帧循环动画：
        - 待机（idle）：轻微上下浮动
        - 攻击（attack）：必杀技动作
        提示词：「Loop animation, fighting game idle pose,
                  pixel art, 8 frames, KOF97 style」

Step 4  命名必杀技，写技能说明
        儿子来写（1-2句话）：
        「在茶卡盐湖，少年踩在盐面上，
         利用镜面反射制造幻影，令敌人无法分辨真假」

Step 5  导入游戏
        爸爸把动画帧做成 Phaser.js Sprite Sheet
        在「丝路武者列传」页面展示
```

### 推荐 AI 工具

| 工具 | 用途 | 特点 |
|------|------|------|
| **可灵 AI（Kling）** | 照片→动画视频 | 国内产品，无需VPN，效果很好 |
| **Midjourney** | 照片→像素风格精灵图 | 风格控制最强 |
| **DALL·E（ChatGPT）** | 快速生成参考图 | 随时可用，门槛低 |
| **Runway Gen-3** | 图片→动画帧 | 动作流畅度好 |
| **Aseprite** | 手动调整像素动画帧 | 专业像素动画工具，一次性买断约$20 |
| **Pika 2.0** | 短动画生成 | 适合做3-5秒动画片段 |

> 💡 **最实用路线**：手机现场用 DALL·E 生成像素图预览，回酒店用 Midjourney 精修，用可灵 AI 生成动画。

### 真人照片拍摄技巧

**动作选择：**
- 跳跃类：在沙丘、盐湖等开阔地带效果最好
- 出拳/踢腿类：侧面角度拍，动作要夸张，不要害羞
- 背影类：背对镜头，面向壮阔风景，双臂张开

**构图建议：**
- 人物占画面 1/3，背景占 2/3（背景才是这张图的意义）
- 逆光拍轮廓感更强，AI 更容易生成精灵图
- 多拍几张，回去再筛选

**怎么把爸爸和儿子都拍进去：**
- 用三脚架 + 手机自拍模式（10秒延迟）
- 或找路人帮拍一张（简单说：「帮我们拍个跳起来的照片」）

## 技术实现

### 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 游戏引擎 | **Phaser.js 3** | 成熟的 Web 2D 游戏框架，支持物理、动画、场景管理 |
| 语言 | **TypeScript** | 类型安全，便于儿子后期阅读和理解代码结构 |
| 构建工具 | **Vite** | 开发体验极快，热更新即时生效 |
| 美术资源 | AI生成（Midjourney / DALL·E）+ 儿子手绘草图 | 像素风格，尺寸统一 |
| 音频 | Suno AI 生成，导出 MP3/OGG | 每章独立BGM |
| 部署 | **Vercel**（自动 CD，push 即上线） | 免费，生成可分享链接 |
| 版本管理 | GitHub | 每天提交，记录开发过程 |

### 父子开发分工

| 爸爸负责 | 儿子负责 |
|---------|---------|
| 游戏架构设计 | 关卡内容设计（这一关有什么、怎么玩） |
| Phaser 场景、物理、动画 | 角色草图提供、美术方向决策 |
| 数据结构设计（知识卡、地图、NPC） | 知识卡文案撰写（自己的语言） |
| 代码 review 和讲解 | **学习并实现简单功能**（见下方） |
| 性能优化、bug 修复 | 每日测试，提 bug 报告 |
| 推广页面开发 | 推广页面内容和视觉方向 |

**儿子可以真正动手写的代码（爸爸教）：**
```
第一周   HTML/CSS 基础 → 做知识卡的样式
第二周   JavaScript 基础 → 写一个点击事件、弹出知识卡
第三周   Phaser 入门 → 在场景里添加一个 NPC，设置对话文本
第四周   数据驱动 → 用 JSON 文件添加新的知识卡内容
```

> 爸爸不是替儿子写，是**带他一起写**。他写出来的那几行代码，是整个游戏里最值钱的部分。

### MVP 版本（最低交付目标）

```
✅ 一张可交互的丝绸之路地图（Phaser 场景）
✅ 5个章节入口，每章有独立场景
✅ 主角可以在场景内移动
✅ 30张知识卡（JSON 驱动，儿子可独立添加）
✅ 每章独立 BGM（Suno 生成）
✅ 旅途真实照片作为场景背景
✅ Vercel 部署，有公开链接可分享
```
