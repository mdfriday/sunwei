# 07 · AI 工具指南

> AI 是这趟旅行的第三个队员。
> 不是用来替代思考的，是用来把父子俩的想法**快速变成真实可见的东西**。

---

## 核心理念

```
儿子提想法  →  父子讨论设计  →  爸爸架构实现  →  AI 生成素材  →  儿子参与内容  →  放进游戏
```

爸爸是专业程序员，AI 在这个团队里的分工不是「帮爸爸写代码」，而是：
- 替代需要专业设计师才能完成的**美术、音乐、视频**工作
- 让儿子能独立完成本来需要大量工具学习成本的**创作任务**
- 作为爸爸的**架构讨论伙伴**（Claude 讨论设计方案比搜索文档快）

---

| 类别 | 工具 | 用途 | 儿子参与度 |
|------|------|------|-----------|

## 一、游戏开发（代码）

### 爸爸的工具链

爸爸是专业程序员，有自己成熟的工作流。AI 在这里扮演的角色是**加速器**，不是替代者。

| 工具 | 用途 |
|------|------|
| GitHub Copilot | 日常代码补全，加速 Phaser 场景开发 |
| Claude | 讨论游戏架构设计、数据结构，比查文档快 |
| ChatGPT | 快速查 Phaser.js API 用法、解决报错 |

**实际使用场景示例：**
```
爸爸：「我想设计一个知识卡系统，卡片数据用JSON存，
       支持翻转动画，点击地图标记触发，
       Claude 你觉得数据结构怎么设计合理？」

Claude：给出3种方案 → 爸爸选最适合的 → 自己实现
```

### 儿子的代码学习路径

儿子已经做过 Web 游戏，有基础。这趟旅行是他真正进入「可以读懂和修改代码」阶段的机会。

**爸爸带儿子的节奏（每晚15-20分钟）：**

```
第一周（武汉→兰州）
  爸爸讲：HTML 结构 + CSS 样式是怎么控制游戏界面的
  儿子做：修改知识卡的颜色和字体，让它看起来更好看

第二周（西宁→敦煌）
  爸爸讲：JavaScript 事件和函数
  儿子做：写一个点击地图标记弹出对话框的函数

第三周（敦煌→张掖）
  爸爸讲：JSON 数据结构
  儿子做：独立向 knowledge-cards.json 添加新的知识卡

第四周（张掖→武汉）
  爸爸讲：Phaser 场景是怎么工作的
  儿子做：在场景里添加一个新 NPC，设置名字和对话
```

> 他写出来的那几行代码，哪怕只有10行，是整个游戏里最值得保留的部分。

**实用提示词模板：**
```
「用HTML做一个丝绸之路地图游戏，
 地图上有5个可以点击的地点，
 点击后弹出知识卡，
 知识卡包含标题、图片占位符、一段文字，
 风格是古朴的丝绸之路感觉」
```

## 二、图片生成（美术）

### 工具：Midjourney / DALL·E（ChatGPT内置）

**这是儿子最能主导的环节。**

他在旅途中画的草图 → 拍照 → 发给AI → 生成游戏美术资源

**工作流程：**

```
Day 4（西安兵马俑）：
儿子手绘「兵马俑士兵」草图
拍照上传给DALL·E：
「把这个草图做成像素风格游戏角色，
 16x16像素，复古游戏美术风格，
 透明背景」
→ 得到游戏角色素材
```

**按游戏章节的图片需求：**

| 章节 | 需要生成的图片 | 参考素材来源 |
|------|--------------|------------|
| 序章 | 长安城背景、主角立绘 | 西安城墙照片 |
| 第一章 | 黄河渡口场景、黄土高原地图背景 | 兰州黄河照片 |
| 第二章 | 青海湖星空背景、盐湖镜面场景 | 黑马河真实星空照片 |
| 第三章 | 戈壁沙漠场景、飞天角色、骆驼商队 | 敦煌壁画照片、鸣沙山照片 |
| 第四章 | 嘉峪关关城、彩色丹霞山脉 | 张掖丹霞照片 |
| 推广页 | 游戏封面图、章节插画 | 全程最美照片 |

**实用提示词模板：**
```
「像素风格游戏场景，丝绸之路主题，
 青海湖夜晚，星空倒映在湖面，
 远景有雪山，近景有帐篷和篝火，
 16-bit游戏风格，暖色调」
```

**给儿子的任务：**
- 每到一个地方，画一个他印象最深的东西的草图
- 晚上一起把草图变成游戏素材
- 他是游戏的「首席美术」

## 三、音乐生成（BGM）

### 工具：Suno AI

**Suno 可以用文字描述生成完整的音乐，包括旋律、伴奏、甚至歌词和人声。**

这是孩子最容易上手、最有成就感的环节——输入几个词，30秒后听到一首真实的歌曲。

**按游戏章节的音乐风格：**

| 章节 | 音乐风格 | Suno 提示词方向 |
|------|---------|----------------|
| 序章·长安 | 古典中国风，宏大 |「Chinese traditional, epic, silk road departure, orchestral」 |
| 第一章·黄土 | 西北民谣，黄河号子 | 「Chinese folk, Yellow River, drums, earthy, adventure」 |
| 第二章·高原 | 空灵藏族风，辽阔 | 「Tibetan ambient, crystal lake, night sky, ethereal, peaceful」 |
| 第三章·戈壁 | 丝路沙漠风，神秘 | 「Middle Eastern desert, camel caravan, ancient silk road, mysterious」 |
| 第四章·丹霞 | 壮阔史诗感 | 「Epic cinematic, colorful mountains, geological wonder, triumphant」 |
| 终章·归途 | 温暖，怀念 | 「Warm acoustic, homecoming, father and son, journey's end, hopeful」 |

**特别项目——父子主题曲：**

旅行结束后，用Suno生成一首属于这趟旅行的歌：

```
歌词方向（儿子来写）：
「我们从武汉出发，走过黄河边，
 在青海湖看见了银河，
 爸爸开车，我画游戏，
 30天，我们做了一件事」

风格：轻快、温暖、有点民谣感
```

**给儿子的任务：**
- 他负责决定每一章的音乐「感觉」（用大白话描述）
- 爸爸把描述翻译成Suno提示词
- 一起听，选最喜欢的版本

## 四、视频制作（旅行记录）

### 工具：CapCut（剪映国际版）+ Runway

**两个用途：**
1. 每周剪一个旅行花絮视频（发给家人看）
2. 旅行结束后剪一个游戏宣传片

**每周花絮视频（周日晚上，30分钟）：**

```
素材：本周拍的照片 + 视频片段
工具：CapCut AI自动剪辑
步骤：
  1. 把本周素材导入CapCut
  2. 选「AI自动剪辑」，选音乐风格
  3. 微调字幕和节奏
  4. 导出，发给家人
```

**游戏宣传片（旅行结束后，1天）：**

```
内容：
  - 游戏画面录屏
  - 旅途中的真实场景对应展示
  - 「这个场景来自青海湖那晚」
  - 父子一起做游戏的花絮
  - Suno生成的主题曲作为BGM
时长：2-3分钟
风格：纪录片感 + 游戏介绍混合
```

**Runway 用于：**
- 把静态图片生成短视频（如：让飞天壁画「动起来」）
- 游戏片头动画生成

## 五、游戏推广页面

### 工具：v0.dev + Claude

**游戏做好之后，需要一个「介绍页面」让别人了解这个游戏。**
这个页面本身也是父子项目成果的一部分。

**页面结构：**

```
1. 封面：游戏名 + 主视觉图（AI生成）
2. 故事简介：「一对父子，一条丝绸之路，一个游戏」
3. 游戏章节预览：5章节截图 + 简介
4. 知识卡展示：展示几张有趣的知识卡
5. 旅途照片墙：真实旅行照片
6. 游戏入口按钮：「开始游戏」
```

**用v0.dev生成：**
```
提示词：
「做一个游戏介绍网页，
 风格是古典丝绸之路 + 现代简洁的结合，
 主色调是沙漠金色和深夜蓝，
 包含游戏章节卡片、知识卡展示区、照片墙，
 适合手机浏览」
```

**给儿子的任务：**
- 他来写游戏介绍文案（用自己的话）
- 他来选哪些旅途照片放进页面
- 他来决定配色方案

## 六、知识查询（每晚的问题）

### 工具：ChatGPT / Perplexity AI

**这是儿子每天提问的主战场。**

每晚父子项目时间，儿子把今天的问题输入AI：

```
儿子：「为什么青海湖是咸水湖？」

AI回答 → 父子一起读 → 整理成知识卡文字 → 放进游戏
```

**教儿子用AI提问的技巧：**

| 普通问题 | 更好的问法 |
|---------|-----------|
| 「青海湖为什么是咸的」 | 「用12岁能理解的语言解释青海湖为什么是咸水湖，100字以内」 |
| 「壁画怎么保存」 | 「莫高窟壁画能保存1000年的3个最重要原因是什么，每个原因一句话」 |
| 「丝绸之路是什么」 | 「如果我是一个丝路商队的少年，从长安出发，第一天会遇到什么，用故事方式描述」 |

**提问三步法（教给儿子）：**
```
1. 把问题说清楚
2. 告诉AI你想要什么格式（列表/故事/简短）
3. 如果回答不满意，说「再简单一点」或「举个例子」
```

**这趟旅行结束后，他会自然掌握：**


## 十、一句话原则
