# 06 · 沿途美食指南

> 原则：找街边小店，找本地人排队的地方，不去网红打卡点。
> 吃饭也是旅行素材——每一道食物背后都有一个游戏知识卡。

---

## 武汉（出发）

**早餐是武汉的灵魂，出发前吃一顿正经的。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| 热干面 | 找街边小推车或社区早餐店，不是连锁 | 要芝麻酱厚的那种 |
| 豆皮 | 老通城或社区早餐铺 | 糯米 + 豆腐皮 + 肉末 |
| 面窝 | 路边早餐摊 | 中间有洞的油炸面圈 |
| 蛋酒 | 早餐店配套 | 米酒 + 鸡蛋，暖胃出发 |

> 💬 问儿子：**"武汉人为什么把早餐叫'过早'？"**

---

## 洛阳（Day 1）

**洛阳人吃饭有规矩：先喝汤。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **牛肉汤** | 老城区街边汤馆，早7点前去 | 洛阳早餐第一选择，配烧饼 |
| **不翻汤** | 老城区小巷，卖早点的店 | 绿豆面薄饼 + 杂烩汤，洛阳独有 |
| 浆面条 | 本地面馆 | 发酵酸浆煮面，外地人接受需要适应 |
| 洛阳水席 | 找有年头的老店（不是景区旁边的） | 24道菜，汤汤水水为主，量大 |

> 💡 牛肉汤 + 烧饼 = 洛阳最地道的早餐，5-10元，找人多的小店准没错。

> 💬 问儿子：**"为什么洛阳人吃饭先喝汤？"**

---

## 西安（Day 3-5）

**西安的食物和丝绸之路直接相关，每一道都有历史故事。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **牛羊肉泡馍** | 找本地人聚集的老店（永兴坊周边，不是回民街） | 馍要自己掰，掰得越碎越好，告诉服务员"口汤"或"单走" |
| **biángbiáng面** | 城内普通面馆，不是景区 | 宽如腰带，辣子一泼，香 |
| **腊汁肉夹馍** | 街边小店，现做现卖 | 肉要肥瘦相间，饼要脆 |
| 秦镇米皮 | 早餐时间，路边米皮摊 | 和陕北凉皮不同，更软糯 |
| 甑糕 | 早餐街边摊 | 糯米 + 红枣 + 红豆蒸成，甜软 |
| 葫芦头泡馍 | 本地老馆子 | 猪大肠 + 馍，重口味但是经典 |

> 💡 **泡馍找法则**：门口有人在掰馍的，就是对的店。

> 💬 游戏知识卡：**"丝绸之路上，商队带走了什么食物？带来了什么食物？"**
> （胡椒、葡萄、核桃都是丝路带来的）

## 天水（Day 5）

**天水是麻辣烫的发源地——但和你熟悉的不一样。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **天水麻辣烫** | 城内任意街边小店 | 不是串串，是汤锅，辣而不燥，当地人早中晚都吃 |
| **天水呱呱** | 早餐或下午茶时间，街边小摊 | 蕨根粉凉拌，加辣椒油、醋、芝麻，天水独有 |
| 浆水面 | 本地面馆 | 发酵酸汤面，夏天清爽 |
| 天水凉粉 | 路边摊 | 比一般凉粉更弹，配料足 |

> 💡 天水麻辣烫2024年因为一位网红走红，但当地人早就知道这个味道。找小街巷里的，不要排队1小时的那种。

## 兰州（Day 6-7）

**"牛大"不是兰州拉面，是兰州牛肉面，差别很大。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **兰州牛肉面（牛大）** | 早7-9点，任意一家街边面馆 | 清汤、红辣油、白萝卜、绿葱蒜；要"二细"（中等宽度）；一碗8-12元 |
| **酿皮** | 早餐或午饭，街边小店 | 类似凉皮但更筋道，配辣椒油、芥末 |
| 手抓羊肉 | 清真餐厅，晚饭 | 大块、不加调料、蘸盐吃 |
| 甜醅 | 街边小摊 | 发酵燕麦，微甜微酸，消化好 |
| 灰豆子 | 早餐摊、街边 | 豌豆煮烂加红糖，暖胃 |

> 💡 **牛大规则**：进店先告诉老板宽细（毛细/细/二细/三细/韭叶/宽/大宽），加不加辣，不用看菜单。

> 💬 游戏知识卡：**"兰州为什么是丝绸之路的重要节点？黄河在这里有什么作用？"**

## 西宁（Day 7-8）

**青藏高原的饮食：高热量、暖身体，每一样都有高原适应的逻辑。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **手抓羊肉** | 清真餐厅，晚饭 | 青海的羊吃草长大，膻味极淡 |
| **尕面片** | 本地面馆 | 手撕面片煮汤，配羊肉或蔬菜，青海家常主食 |
| **炕锅羊肉** | 本地餐厅 | 铁锅焖羊肉 + 土豆，香浓 |
| 藏式酥油茶 | 藏族餐馆或寺庙附近小店 | 咸的，黄油味，补充高原能量 |
| 酸奶 | 街边摊、早餐店 | 比内地酸奶浓3倍，加蜂蜜 |
| 馓子 | 早餐时间 | 油炸面条圈，配奶茶或稀饭 |
| 青稞馍 | 早餐 | 青稞面做的馒头，有嚼劲，高饱腹感 |

> 💡 西宁是高原适应的关键一天，吃热的、喝热的，不要喝酒，不要吃太撑。

> 💬 游戏知识卡：**"酥油茶为什么是咸的？高原上为什么要喝这个？"**

## 青海湖·黑马河周边（Day 9-10）

**这一带以牧区食物为主，选择不多，但有独特体验。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **手抓羊肉** | 黑马河镇小餐馆 | 牧区直供，新鲜，价格实惠 |
| 青稞炒面（糌粑） | 藏族家庭或小店 | 炒青稞面 + 酥油，高热量行路干粮 |
| 酥油茶 | 当地小馆子 | 高原夜晚保暖必备 |
| 馒头 + 咸菜 | 便利店或小店 | 露营早餐备用 |

> 💡 露营那天晚上，在帐篷门口用炉具烧一壶热水，泡一杯热茶，比任何餐厅都有味道。

## 敦煌（Day 14-15）

**敦煌的核心食物是"驴肉黄面"，这是真正的本地特色。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **驴肉黄面** | 敦煌市区普通餐馆，本地人午饭首选 | 黄色细面 + 卤驴肉，面条劲道，汤鲜；找没有网红标签的小店 |
| **羊肉粉汤** | 早餐，街边汤锅 | 粉条 + 羊肉 + 蔬菜，一碗暖胃 |
| 杏皮水 | 路边小摊、超市 | 敦煌杏子熬制，酸甜，解渴，当地人夏天必喝 |
| 敦煌馕 | 馕坑烤制，路边现卖 | 圆形大饼，烤香，耐饿，适合路上带着吃 |
| 炒拨拉 | 本地烧烤摊，夜市 | 羊杂 + 孜然铁板炒，配馕 |

> 💡 **驴肉黄面找法**：不要找门口写"网红"的，找坐满本地人、没有英文菜单的小馆子。

> 💬 游戏知识卡：**"敦煌的杏子为什么这么好吃？和丝绸之路有什么关系？"**

## 嘉峪关（Day 16）

**嘉峪关是边塞城市，食物粗犷实在。**

| 食物 | 怎么找 | 备注 |
|------|--------|------|
| **炒炮仗** | 本地面馆 | 短粗面条 + 羊肉 + 西红柿爆炒，甘肃最具特色的面食之一 |
| 搓鱼面 | 家常面馆 | 手搓成鱼形的面，配羊肉臊子 |
| 羊肉串 | 夜市或路边摊 | 西北羊肉串，孜然味浓，比新疆略有不同 |
| 羊肉拉条子 | 面馆 | 新疆拉面风格，甘肃版本 |

## 路上的通用原则

### 怎么找好吃的

```
1. 看人，不看店——门口有当地人排队的，进去
2. 看时间——本地人吃饭时间去（早7-8点，午11:30-12:30）
3. 看语言——菜单只有中文的，更可能是本地店
4. 看装修——越普通越好，瓷砖墙、塑料凳子，往往更香
5. 问司机或酒店前台——"你们自己去哪里吃？"
```

### 父子点餐策略

- 每顿饭点**一道本地特色 + 一道孩子爱吃的**
- 孩子不喜欢的食物，不强迫尝
- 但鼓励他闻一闻、问一个关于这道菜的问题

### 高原饮食注意

| 地区 | 注意 |
|------|------|
| 西宁以上 | 吃热食，少吃生冷 |
| 高原露营 | 晚餐不要太油腻，消化慢 |
| 戈壁路段 | 多喝水，备好干粮 |
| 全程 | 孩子肠胃敏感，新食物少量尝试 |
