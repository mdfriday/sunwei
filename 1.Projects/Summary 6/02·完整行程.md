# 02 · 完整行程计划

> 武汉出发，青甘大环线，约30天，全程国道/高速，轿车自驾。
> 原则：不赶路，每天驾驶不超过5小时，孩子状态优先。
> 车辆：丰田 Yaris（二厢），全程不离主道。
> 方向：**顺时针**（先甘肃走廊，后青海高原）——海拔循序渐进，安全第一。

---

## 车辆说明·丰田 Yaris

**① 加装车顶行李箱（强烈建议）**
Yaris 后备箱约 270L，装两人30天装备会塞满。
加装 300-400L 硬壳车顶箱，把帐篷/睡袋/衣物放上去，问题解决。

**② 全程实际最高点：日月山垭口（3520m）**
位于西宁→青海湖路段（G109），Yaris 在此约有 **63% 功率**。
坡度平缓，对普通轿车友好，关空调匀速通过即可。

> ℹ️ 橡皮山（4100m）是 G109 西宁直达格尔木的捷径，为进藏方向道路，**不在本次主道行程上**，无需担心。

---

## 为什么选顺时针

| 对比 | 逆时针（先青海） | **顺时针（先甘肃）✅** |
|------|----------------|----------------------|
| 高海拔时机 | 出发第9天就到3200m | 出发第18天才到3200m |
| 身体适应 | 还未适应就进高原 | 有两周时间逐步适应 |
| 海拔变化 | 先高后低 | 先低后高，循序渐进 |
| 出问题时 | 高原进退两难 | 随时沿G30返兰州下高原 |
| 孩子状态 | 旅途初期体力最好，但高原风险早 | 进高原时已有旅行经验，更从容 |

**⚠️ 日月山垭口（3520m）— Yaris 重点路段：**

```
上山前：
  - 关闭空调
  - 切换手动模式，选 M3 挡

爬坡时：
  - 匀速行驶，不急加速
  - 转速保持 2500-3500 RPM
  - 车速 50-70km/h 是正常的

山顶：
  - 停车10分钟，拍照，感受一下
  - 这是全程最高的地方

下坡时：
  - 保持 M3 或 M2，发动机制动
  - 不要长时间踩刹车
```

> Yaris 在 3520m 约有 63% 功率，爬坡会略慢，但日月山坡度平缓，完全没问题。

**到西宁后：**
- 到酒店直接休息，不安排活动
- 多喝水，从高原恢复到 2200m

## 手动档使用指南（自动变速箱手动模式）

> Yaris 搭载 CVT 或 AT，手动模式（M档/拨片）是锁定模拟挡位，防止变速箱自动升挡。

### 全程只有一段真正需要手动模式

```
日月山垭口（Day 19）：青海湖 → 西宁途中
海拔：3200m → 3520m → 2200m
上坡用 M3，下坡用 M3 或 M2
```

其他所有路段：D 挡正常行驶，不需要切换。

---

### 上坡（日月山爬坡）

```
步骤：
1. 进入山口弯道前，车速降至 60km/h 以下
2. 档杆拨到 M 档，选择 M3
3. 目标转速：2500-3500 RPM
4. 油门保持稳定，不猛踩猛松
5. 关闭空调（节省约10-15%功率）
6. 车速自然降到 50-60km/h，正常，不用管
```

**判断挡位是否合适：**
- 转速低于 2000 RPM → 降一挡
- 转速高于 4000 RPM → 升一挡
- 2500-3500 RPM → 正好

---

### 下坡（日月山下山）

```
正确做法：
1. 下坡前换入 M3（或 M2）
2. 用发动机制动控制车速（会听到发动机嗡嗡声，正常）
3. 目标车速 40-60km/h
4. 刹车只用来微调，不要长踩

错误做法：
❌ D 挡 + 长时间踩刹车 → 刹车过热 → 危险
```

**简单记忆：下多高的坡，就用多低的挡。**
