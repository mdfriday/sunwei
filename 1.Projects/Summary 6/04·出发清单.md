## 出发倒计时

### 出发前一周

```
[ ] 全车保养完成
[ ] 备胎气压检查
[ ] 莫高窟门票预约（官网，必须提前）
[ ] 手机下载离线地图（奥维互动地图）
[ ] 确认沿途关键酒店预订
[ ] 通知家人完整行程计划
[ ] 帐篷在家试搭，确认无破损
```

### 出发前一天

```
[ ] 充电宝全部充满
[ ] 手机清理储存空间（至少50GB）
[ ] 气罐数量确认（至少6罐）
[ ] 急救包清点
[ ] 打印一份行程计划放车内
[ ] 后备箱整理，重物放下层
```

### 出发当天早晨

```
[ ] 油箱加满
[ ] 告知家人出发时间和Day 1落脚点
[ ] 确认孩子状态良好
[ ] 查当天天气（避强降雨路段）
```
