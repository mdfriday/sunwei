# Claude.ai

**Type**: other

## Facts

- 用户可能之前使用过的平台。
- 相比 [[Claude Code]]，缺乏直接访问文件和终端的能力，通常需要复制粘贴代码。
- Web 端访问地址为 [[Claude.ai]]/code，可通过侧边栏'Code'标签进入

## Connections

- [[claude-code|Claude Code]] related-to [[claude-ai|Claude.ai]]: 与 Claude.ai 不同，Claude Code 拥有直接访问文件、终端和整个代码库的能力，无需复制粘贴。
