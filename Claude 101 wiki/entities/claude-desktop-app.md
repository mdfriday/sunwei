# Claude desktop app

**Type**: tool

**Aliases**: Claude desktop app

## Facts

- 提供三种工作模式：Chat、Cowork 和 Code
- 需要安装此应用才能使用桌面扩展程序
- 用于本地文件访问、浏览器控制和原生应用程序集成
