# Google Drive

**Type**: tool

## Facts

- 可作为 [[Research]] 的集成数据源
- 可连接的外部存储工具，用于向项目的知识库添加文档
- [[Claude]] 可将生成的文件直接保存到此处
- 使用需开启 Allow limited network access 权限
- 云存储服务，用于文档管理和搜索品牌指南等
- 可作为企业搜索的文档连接器
- 用户需授权访问权限
- Connected tool that can be integrated with [[Claude]] via [[Enterprise search]]
- Users have permission-based access to content
