# Slack

**Type**: tool

## Facts

- 可作为 [[Research]] 的集成数据源
- [[Claude]] 集成的工具之一，用于协作环境中的使用，未来版本包括 Claude in [[Slack]]。
- [[Claude]]可直接集成，允许在频道和线程中获取帮助
- 用于团队协作、会议准备和在上下文中快速回答
- 作为连接工具之一，[[Claude]] 可通过 [[Slack]] 进行工作。
- 可通过 Cowork 连接器访问，用于获取消息信息
- 沟通工具，支持搜索频道消息和团队讨论内容
- 可作为企业搜索的聊天连接器
- 支持搜索 [[Slack]] 对话历史
- Connected tool for [[Team collaboration]]
- [[Claude]] can integrate with [[Slack]] for collaboration tasks

## Connections

- [[claude|Claude]] related-to [[slack|Slack]]: Claude 提供集成到 Slack 工具的版本以支持协作工作流。
- [[slack|Slack]] related-to [[enterprise-integration|Enterprise integration]]: Slack作为企业协作平台，支持Claude集成
- [[slack|Slack]] related-to [[enterprise-search|Enterprise search]]: Slack is a connected tool that Enterprise Search can access with permission-based content filtering
