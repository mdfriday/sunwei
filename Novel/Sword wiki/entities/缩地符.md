# 缩地符

**Type**: tool

## Facts

- [[钟倩]]使用带[[小米粒]]返回[[青鹤滩]]渡口的工具。
- [[陈灵均]]认为过于挥霍，但保留以备不时之需。
- [[谢]][[供奉]]手笔，珍贵，[[境界]]不够无法使用
- 可当信物或售卖
- [[谢]][[谢狗]]手制的[[符箓]]
- [[陈平安]]袖中藏有两张，用于瞬间移动[[出拳]]不落[[空]]
- 铺在地上帮助乘客直通[[吞宝鲸]]体内的三幅[[秘境]]（地衣）。
- 分为“云在峰”、“旖旎园”、“[[碧水湖]]”三种。
- 金色材质的[[符箓]]，[[陈平安]]在[[铜臭城]][[金粉坊]]交易后画成两张。
- 用于短距离[[快]]速移动。
- [[金色材质的[[缩地]]符]]，[[陈平安]]用于破开[[天幕]]离开[[鬼蜮谷]]。
- [[老真人]]与[[许供奉]]交换的宝物，其中包含金色材质[[符箓]]。
- [[陈平安]]在大街上使用的[[符箓]]，材质普通，故意给[[庞元济]]看
- [[陈平安]]在受到攻击后祭出，[[一]]退就是十数丈以逃命。
- [[陈平安]]使用的[[符箓]]，转瞬之间便能移动数步。
- [[侯夔门]]与[[陈平安]]在战斗中使用的秘法工具

## Connections

- [[老阵师|老阵师]] uses [[缩地符|缩地符]]: 老阵师在阵法被毁后使用多张缩地符逃离现场。
