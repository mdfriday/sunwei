# 斩龙台

**Type**: tool

**Aliases**: 磨剑石, 斩龙石, 斩龙崖, 半块斩龙台

## Facts

- [[神仙坟]]某尊神像脚下，[[宁姚]]有过承诺的地方
- [[大骊朝廷]][[户部]]秘录的[[龙脊山]]，[[开山]]所得。
- [[陈平安]]拥有[[宁姚]]赠送的[[一]]块形如长条板砚的[[斩龙台]]。
- 从[[龙脊山]][[切割]]而来的[[一]]块石头，用于砥砺[[剑]]锋。
- 昼夜不息不断砥砺[[剑]]锋。
- 巨大，需要消耗两柄[[神兵]]利器作为劈开[[代价]]的地点。
- 用来小[[心]]翼翼磨砺[[炼师]]锋的工具，莫名其妙多出来的小小[[斩龙台]]
- 小巧工具，用于帮[[李宝瓶]]磨砺[[狭[[炼师]]祥符]]
- [[陈平安]]院子里的小[[斩龙台]]，被[[阿良]]拿走打磨。
- 需要深[[落魄山]]里头的大型[[斩龙台]]来替代。
- 巨大的[[落魄山]]崖，用于磨砺[[神兵]]利器，价值连城，有价无市。
- [[宁姚]]送给[[阮邛]]打造[[剑]]的酬[[谢]]，足够买把好剑。
- [[剑]]在被此开锋之前不会显现峥嵘。
- 南方之路需避开[[柳赤诚]]，不找[[死]]可走到[[剑气长城]]。
- [[宁姚]][[家]]的那块，被姓[[大渎]]的年轻[[男子]]询问是否出售。
- 相比世间最佳[[斩龙台]]效果云泥之别但价格便宜。
- 位于[[龙脊山]]那座石崖，[[阮邛]]常去的地方。
- 世间炼养[[飞剑]]的最佳磨石，篆刻有[[天真]][[宁姚]][[字]]样。
- 被誉为世间最珍贵的[[斩龙台]]，[[隋[[左右]]边]]用来磨砺[[本命[[飞剑]]“[[痴心]]”]]。
- 从[[陈平安]]那边买来，到手时只剩下手掌厚薄。
- [[阿良]][[董不得]]在[[苻南华]]赠送的[[斩龙台]]，最大的[[一]]块。
- [[陈平安]]打算收入两座[[窍穴]]当中，磨砺[[剑]]锋。
- [[陈平安]]彻底[[小炼]]两块[[斩龙台]]后，[[化虚]]搁放在两处[[窍穴]]当中。
- [[飞[[剑]][[初一]]十五]]分别入驻其中。
- 黑色石崖上的石条，价值连城。
- 用于磨[[炼师]]或[[磨剑]]，[[宁姚]]可裂出。
- 灵官神像脚下有现成的[[斩龙台]]。
- [[宁府]]最佳[[修道]]之地，天地[[剑气]]凝聚出七彩琉璃之色。
- [[陈平安]][[希望]]吃掉整座[[斩龙台]]，成为新故事。
- 位于[[泥瓶巷]]附近，坚不可摧的大石
- 被[[老秀才]]用[[本命字]][[切割]]成两块
- [[陈平安]]散步之地，[[宁姚]]赠送小小[[斩龙台]]之处
- [[宁府]]所在的小[[落魄山]]，极大，有[[演武场]]。
- 位于[[龙脊山]]/[[龙脊山]]半[[落魄山]]腰的[[谢狗]]大型结构
- [[风雪庙]]与[[真武山]]共同占有，[[阮邛]]打算在此[[开[[落魄山]]立派]]
- 位于[[一]]座不知名大[[落魄山]]的黑色石块，[[陈平安]]抚摸其细腻肌[[理]]。
- 与[[宁姚]]踩在[[剑]]上的神仙有关，具体能磨出什么程度未知。
- [[陈平安]]寄存在[[铁匠铺]]的[[家]]当之[[一]]
- [[周密]]重地，涉及瓜分事宜。
- [[大骊朝廷]][[户部]]秘档记录为[[龙脊山]]
- 半[[落魄山]]腰有[[斩龙台]]石
- [[远古天庭]][[行刑]]台之[[一]]
