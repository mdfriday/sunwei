# Claude Code

**Type**: tool

**Aliases**: Agentic coding environment

## Facts

- 用于编写、测试或交付软件的生产级代码库访问权限工具。
- 具备计划模式（Plan Mode）、[[Git]] 集成，以及本地、IDE 或沙盒云环境。
