# BibDesk

**Type**: tool

**Aliases**: bibdesk.sourceforge.net

## Facts

- Reference management software for [[macOS]]
- Connects with [[BibTeX]] and [[MultiMarkdown]] syntax
- [[macOS]] only [[Reference Manager]].
- Stores everything in a .bib [[BibTeX]] file.
- Compatible with [[LaTeX]] for generating citations and bibliographies.
- Supports custom export templates bound to copy action.
