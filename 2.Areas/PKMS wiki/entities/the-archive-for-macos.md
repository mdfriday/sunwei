# The Archive for macOS

**Type**: tool

**Aliases**: The Archive

## Facts

- App offered by [[zettelkasten.de]] since 2018 to manage [[Zettelkasten]].
- Supports tabs, image capturing, wiki links for searches.
- Software-agnostic philosophy
- Uses plain text files as primary storage
- Search function responsible for features like links
- Alternative tool mentioned alongside [[Obsidian]]
- Used for capturing information
- Recommended as distraction-free [[Zettelkasten]] and note-taking App
- Delivers calm and clean experience with minimal distractions

## Connections

- [[The Archive for macOS]] related-to [[Zettelkasten Method]]: Software-agnostic tool that manages plain text files to support the digital Zettelkasten workflow.
- [[Obsidian]] related-to [[The Archive for macOS]]: Both are tools mentioned as options for note taking
- [[The Archive for macOS]] related-to [[Zettelkasten Method]]: Recommended as a distraction-free Zettelkasten and note-taking App to benefit from low-distraction writing environment.
